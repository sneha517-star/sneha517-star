### 🚀 Featured Projects

#### [MASTER — Multi-Agent Stock Market Trading Environment](https://github.com/sneha517-star)
A simulated market with **6 autonomous trading agents** (momentum, mean-reversion, adversarial, and LLM-powered) making risk-aware decisions under endogenous price impact. Integrated a local LLM (Ollama · Qwen2.5) for explainable trade reasoning, plus circuit breakers and crash simulation for regulator-style risk controls.
`Python` `Flask` `React` `LangChain` `Ollama` `yFinance` `SQLite`

#### [Smart Urban Flood Management System](https://github.com/sneha517-star/Smart_urban_flood_management)
IoT + AI pipeline streaming real-time water-level data from Arduino sensors to GCP, feeding a TensorFlow model that predicts flood risk with **92% accuracy up to 48 hours in advance** — cutting response delays by 35%.
`Python` `TensorFlow` `Arduino` `GCP` `IoT`

#### [Chatbot Using GenAI](https://github.com/sneha517-star/Chatbot_using_GenAI)
A RAG-based LLM chatbot with embeddings and vector search for context-aware answers, built as modular LangGraph workflows to improve retrieval accuracy and reduce response errors.
`Python` `LangChain` `LangGraph` `RAG` `Vector Store`
